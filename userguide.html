Menu Card Catalogue

User Guide

Menu Card Catalogue is a small app that reads the middleware Menu Card Excel workbook and shows it as a tidy, searchable Product Catalogue. Everything happens on your own device — the file is never uploaded anywhere, and the app works offline once loaded. You can install it like a normal app.

1. Opening the app

If a Menu Card has been bundled with the app, it loads automatically on open — you'll go straight to the catalogue (a Bundled badge shows next to the source). You only need to import a file if no card is bundled, or if you want to view a different one.

2. Import a Menu Card (optional)

  1. On the start screen, click the drop-zone and choose the Menu Card .xlsx, or drag the file onto it.
  2. The app reads it instantly and shows a summary — how many services were found for each component (MQ, WLS, WFY, CFT). Any issues appear as warnings.
  3. The catalogue opens automatically and is saved on this device, so it's still there next time you open the app.

The Menu Card usually changes about once a year — just use Re-import (top right of the catalogue) to load the new one. It replaces the old catalogue after you confirm.

2. Browse the catalogue

  • Component / Size pills — tap to filter; tap more than one to combine; "All" clears that row.
  • Search box — type anything (a component, a size, words from a service, a cost) and it matches across every column.
  • Per-column filters — the small boxes under each column heading narrow just that column.
  • Clear resets search and filters. The count shows "X of N services".
  • Click a row to open its full details (complete description and all figures).

3. Save the catalogue as a PDF

Click Save as PDF (top right). It builds a PDF of the whole catalogue (all services, not just what's filtered on screen). On a computer it downloads; on a phone it opens the share sheet so you can save it to Files or send it on.

4. Install it as an app

In your browser's menu choose Install (or "Add to Home Screen" on a phone). It then opens in its own window and works offline.

5. Theme

Use the ◐ button in the header to switch light / dark; it follows your device setting by default and remembers your choice.
